# Automated Service Ticket Assignment System

A beginner-friendly Python demonstration using fictional tickets and team members. Tickets are processed in priority order, assigned to the least-busy qualified team member, and exported to CSV. Unsupported categories are flagged for manual review.

## Run
Open `ticket_assignment.py` in Python IDLE and press **F5** (Run > Run Module). The output is printed in the shell and saved to `assigned_tickets.csv` in the same folder.

## Roadmap
- Read incoming tickets and team skills from CSV files.
- Add assignment capacity limits and audit logs.
- Store ticket history in SQLite.
- Produce Excel reports and a simple dashboard.

This is a standalone demonstration, not an integration with Jira or Salesforce. Do not use real customer or company data.
