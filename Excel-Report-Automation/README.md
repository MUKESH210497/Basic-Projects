# Excel Report Automation with Python

Beginner-friendly **Python / Pandas / OpenPyXL** portfolio project that combines monthly sales CSV files, validates records, removes duplicate order IDs, calculates revenue, and exports a formatted multi-sheet Excel report with a bar chart.

> **Data:** Included transactions are synthetic examples, not actual customer records or business results. Monetary values are illustrative units, not claimed sales.

## Features
- Extract all monthly CSV files from a folder
- Validate required columns, dates, quantities and unit prices
- Deduplicate by order ID (first occurrence wins; review if your business rule differs)
- Separate invalid rows into a review worksheet
- Compute total and regional revenue
- Create `Executive Summary`, `Cleaned Orders`, and `Rejected Rows` worksheets
- Add a regional revenue chart, readable formatting and filters
- Run automated tests

## Requirements
Python 3.10+

From the `Excel-Report-Automation` directory:

```powershell
python -m pip install -r requirements.txt
python -m src.report --input data --output outputs/sales_report.xlsx
python -m pytest -q
```

Open `outputs/sales_report.xlsx` in Microsoft Excel. It is generated by the script and should not be mistaken for an external business report.

## Files
- `src/report.py`: ETL and Excel report generator
- `data/`: two synthetic monthly CSV files
- `tests/test_report.py`: validation and workbook tests
- `requirements.txt`: Python dependencies

## Portfolio talking points
Automated repetitive reporting, performed validation and deduplication, produced summary KPIs and an Excel visualization, and separated invalid data for review.

## Limitations and extensions
The starter script assumes input files have the same schema, deduplicates by order ID, and does not convert currencies. Next steps: add configuration, logging, monthly trends, incremental processing, scheduling, and real data only with permission.
